# Minecraft Mod "HB's Easy Maps"

Improves Vanilla Maps in a number of ways:

Maps are easier to craft, larger, reveal modded structures on the map and can reve al large areas using Cartographers table.

Dependencies:

- Requires HB's Foundation for various utility methods
- Requires HB's Background Chunkloader since loading chunks allows for background map updating

UI Features:

- Map can now be pinned to player's screen in an upper corner by right clicking with the map out
- Pinning the Map also lists current position, biome, and structure data
- Pinning the Compass yields current position, biome, and structure data, and position of last spawn and death

Functional Features:
- Right click the cartographer's table with a map at high enough elevation to scout the area
- This will reveal a large portion of the map and mark nearby structures on the map for you to find
